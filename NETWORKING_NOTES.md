# Сетевое взаимодействие сервисов

## 1. Локальный запуск с 127.0.0.1

Все сервисы работают как процессы на одной машине. 127.0.0.1 означает эту машину.

Пример: order-service обращается к product-service по http://127.0.0.1:8001. Работает, потому что оба процесса на одном хосте.

---

## 2. Контейнер с 127.0.0.1

Внутри контейнера 127.0.0.1 означает сам контейнер, а не хост и не другие контейнеры.

Пример: order-service внутри контейнера обращается к 127.0.0.1:8001, но product-service находится в другом контейнере. Запрос не доходит. Ошибка.

---

## 3. Контейнеры через имена сервисов

Docker создает общую сеть. Контейнеры доступны друг другу по именам сервисов из docker-compose.yml.

Пример: order-service обращается к http://product-service:8000. Docker DNS разрешает имя в IP контейнера. Работает.

---

## 4. Доступ к хосту из контейнера

Для обращения к сервису на хостовой машине используется host.docker.internal.

Пример: контейнер обращается к http://host.docker.internal:9000. Полезно при отладке или если база данных запущена на хосте.
